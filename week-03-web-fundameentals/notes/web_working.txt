        Server:-
            -software program
            -receives request from clients ->  process  -> send response
            role:
                -manages data
                -handles security permissions
                -performs business logiv(authenticating users)
                -operates on backend
            -In modern software engineering we mostly deal with virtual servers in cloud

        
        Request:
            electronic message send client -> server
            -web request follow HTTP  standard:
             Components:
                -URL: the targeted address
                -HTTP method : GET,POST etc - the action intended
                -Headers : metadata about the request ( type of data the client wants, security actions etc)
                -Body:optional data sent

        Response:
            message server -> client
            Components:
                -Status Code: three didgit code indicating the outcome : 200OK, 404 Not Found
                -Headers
                -Body : the actual payload(HTML files , image json)

        The big picture:
            - we type in the url in the browser

            -with that IP address:
                client send synchronous message to Server
                server acknowledges and send the response back
                client confirms the connection
