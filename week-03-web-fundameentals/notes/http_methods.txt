HTTP Methods:
    GET :
        retrieves data from the server
    POST :
        Submit data to server
    PUT :
        update data already on the server
    DELETE : 
        delete data from the server


HTTP status Code:
    1xx : Informational
        request received/ processing
    2xx : Success
        successfully received, understood and accepted
    3xx : Redirect
        further action must be taken/Redirect
    4xx : Client error
        request does not have what it does
    5xx : Server error
        server failed to fulfill an apparent valid request

    
    Some of the status codes:
        200 : OK
        201 : OK Created  - eg:when using POST
        204 : No Content - 
            maybe it comes when you save something - save draft so the server does it and no
            server does the acton like update(PUT/PATCH) but does not have data to show you
        301 : Moved to new URL
        304 : Not Modified(Cached version)
        400 : Bad Request
        401 : Unauthorized   - (Credentials are missing) - who are you?
        403 : Forbidden   - (this client is forbidden to enter) - you cant do this (he knows the person)
        404 : Not Found     - (The server doesnt have the data)
        409 : Conflict  - resource is there - but ddoing this action will break a rule or cause a collision
        422 : unprocessable entity   - the data is for atted but make no sense
        429 : Too many requests
        500 : Internal Server error


Big 3 :
    -safe methods:
        if that is not making any changes to the data in the server
    -idempotent methods:
        if doing that methood 10 times will only produce the same result as doing once
            GET
            PATCH
            DELETE
    -payload(Request body)
        some send the data inside the request body or via the url to the server

JSON:
    standardized way to package information into a plain text format so that different programming
    language can easily understand each other

    6 data types in json:
    -Strings:
        textual data
        wrapped in double quotes - no single quotes
    -Numbers:
        numeric value : int/floats
        dont use quotes, no comma seperator as in 10,000
    -Booleans
        must be lowercase : true/false
    -Null 
        absence of value - not 0
        lowercase - Null
        it gets convertyed to None in Python
    -Objects:
        collection - key-value pairs wrapped in - {}
        keys : string in double quotes
        key-value seperated by :
        pairs seperated by comma
    -arrays:
        ordered list of values wrapped in []
        has a key like -
        eg: "tags" : ["electronics, "work", "pc]


    
    Nested Objects: Onbjects within an Objects


    Serialization:
        python - its  called dumping/encoding
        python dict/list  -> JSON using:
            json.dumps() : object -> json string               -> memory : Ram    use in the later process
            json.dump() : object -> writes directly to the file   -> memory : Disk
               here is where none becomes null, True becomes true

    Deserialization
        python - its called loading/decoding
        JSON -> python dict/list using:
            json.loads(): decode JSON string
            json.load : decode JSON data directly to the file
