Selection Sort:
    -scan the full list and find the smallest one
    -move it to the sorted part
    -remaining :- unsorted part
    -now check the unsorted part and do the same process
    -move the smallest part to the sorted part
    -remaining - unsorted part
  Time Complexity : O(n^2)
  Space Complexity ; O(1)

Insertion sort:
    -first element - sorted part
    -second element compare with first
    -move if smaller
   Shifting happens to leave space to insert the value at a specific space


Timsort
merge sort + Insertion sort
Time Complexity : O(NlogN)   
Space Complexity : O(N)

Stack
    for undo/redo:
        there will be two stacks:
            -when you do something - everything is stored in undo stacks
            -then you click "undo" - the item gets popped
            -that will be stored in the redo stack
            -when you click "redo" - the item gets popped from redo
            -it will be pushed back to undo stack

    Implementing:
        we can use:
            -array/list
            -linked list

    the system will not inherently know  its a stack
    we make it a stack:
        -either we as a team agree that we will only do operations at the end(LIFO)
        -else we set the quadrail:
            we wrap it inside a class and define the methods in it
            so when a developer creates a stack class they can do any operations other than the listed ones

    there is no in-built data structure called stack
    we just create a list/array or linkedlist and then set stack-based rules to it
    there is no inbuilt push, pop ,peek operation - those are hypothetical stack operations
    this is truee for modern languages - but older Java / C++ HAVE sTACK DATATYPE

Recursion:
     a recursion is used when you dont know how much time you have to repeat the process and at each stage you have to do exactly the same operation
    Whwn a function is called:
        -the call stack creates a new layer
        -it is pushed into the stack
        -when next function is called
        -it is pushed on top of that existing Stack
           this helps in tracking the way back unlike loops which has the memory of only the current state

    Recurssion will have:
    -Base Case:
        Condition after which the looping will not happens
    -Recursive Case:
        the steps to repeat

    Call stack:
        internal runtime structure that tracks these calls is the Call Stack
    Endless recursion(absence of base case):
        creates stack overflow - run out of memory
